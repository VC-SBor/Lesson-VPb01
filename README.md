# Lesson-VPb01 — Расписание занятий

Настольное приложение на Python (`tkinter`) для управления расписанием занятий,
вебинаров и учебных сессий с функцией напоминаний.

## Возможности

- **Таблица-расписание** с колонками: название события, дата, время начала, время напоминания.
- **Сворачиваемая таблица** — по умолчанию свёрнута; кнопки «Развернуть» / «Свернуть».
- **Управление записями** — добавление, редактирование (двойной клик по строке), удаление.
- **Напоминания** — проверка расписания каждые 30 секунд, всплывающее окно с названием, датой и временем события; повторные напоминания не выводятся.
- **Сохранение расписания** — данные автоматически пишутся в JSON-файл и восстанавливаются при следующем запуске.

## Требования

- Python 3.x
- Модуль `tkinter` (входит в стандартную поставку Python на Windows)

## Запуск

```bash
python schedule_app.py
```

## Формат данных

Расписание хранится в файле `schedule_data.json` рядом со скриптом.
Пример записи:

```json
[
  {
    "name": "Лекция",
    "date": "15.10.2026",
    "time": "10:00",
    "reminder_minutes": 15,
    "reminded": false
  }
]
```

Если файл отсутствует или повреждён, приложение запускается с пустым расписанием.

## Структура проекта

```
schedule_app.py       # исходный код приложения
prompt.txt            # исходное техническое задание
schedule_data.json    # файл с расписанием (создаётся автоматически)
```

## Технические детали

- Интерфейс построен на `tkinter` и `ttk.Treeview`.
- Проверка напоминаний выполняется через `root.after()` в главном потоке (потокобезопасно).
- Данные хранятся в памяти (список словарей) и синхронизируются с JSON-файлом.
- Интерфейс полностью на русском языке.
