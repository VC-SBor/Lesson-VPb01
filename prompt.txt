Создай настольное приложение на Python с использованием модуля `tkinter` для управления расписанием занятий, вебинаров и учебных сессий с функцией напоминаний.

**Требования к интерфейсу:**

1. **Таблица-расписание** с колонками:
   - Название события
   - Дата события
   - Время начала события
   - Время напоминания (за сколько минут или в какое время напомнить)

2. **Сворачиваемая таблица:**
   - По умолчанию таблица свёрнута (занимает минимум места на экране)
   - Кнопка «Развернуть» — открывает таблицу для просмотра и редактирования записей
   - Кнопка «Свернуть» — возвращает таблицу в компактное состояние

3. **Управление записями:**
   - Добавление нового события
   - Редактирование существующего события
   - Удаление события

4. **Система напоминаний:**
   - Приложение проверяет расписание каждые 30 секунд
   - Когда наступает время напоминания, выводится всплывающее окно (messagebox) с информацией: название, дата и время события
   - Повторные напоминания не выводятся (однократное срабатывание)

**Технические детали:**
- Используй `tkinter` и `ttk.Treeview` для таблицы
- Для планировки проверки используй `threading` или `root.after()`
- Данные храни в памяти (список словарей) — без базы данных
- Интерфейс должен быть на русском языке
